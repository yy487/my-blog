# 评论、点赞和分享

文章底部提供系统分享和复制链接。填入评论服务地址后，显示点赞、评论和回复；未配置服务时不向读者展示不可用的评论表单。

评论和点赞按规范化文章路径分别保存。查询参数和锚点不改变文章身份，中文路径统一解码一次。修改文章内容不会清空互动；修改文章 URL 则需要迁移 Waline 数据中的路径。

## 创建评论服务

1. 使用 GitHub 账号登录 Vercel，选择 Hobby/Personal 免费方案。
2. Add New → Project → 导入 `yy487/my-blog`。GitHub 授权只选择需要的仓库即可。
3. Project Name 可填 `yuyu-comments`，Framework Preset 选择 Other。
4. Root Directory 选择 **`services/waline`**。保持使用该目录自带的 `vercel.json` 和 pnpm 锁文件。
5. 评论数据库用独立的 Neon PostgreSQL：通过 Vercel Storage/Marketplace 添加 Neon 免费数据库并连接到评论项目，或在 Neon 建库后把连接地址填入 Vercel 的 `DATABASE_URL` 环境变量。服务也兼容集成生成的 `POSTGRES_URL`。这里不使用 Cloudflare 下载统计的 D1 数据库。
6. 在 Neon 的 SQL Editor 中执行仓库内 `services/waline/schema.sql` 的全部语句。此文件可以重复执行，不会删除已有表。
7. 在 Vercel 评论项目的环境变量中填写下表，再部署。所有凭据只保存在 Vercel，不写入 Pages CMS 或 Git 仓库。

| 变量 | 值 |
| --- | --- |
| `DATABASE_URL` | Neon 生成的 PostgreSQL 连接地址；集成已提供 `DATABASE_URL`/`POSTGRES_URL` 时不用重复填 |
| `OWNER_EMAIL` | 瑜瑜自己的管理邮箱，用于首次注册管理员 |
| `AUTHOR_EMAIL` | 接收待审评论提醒的管理邮箱，可与上一项相同 |
| `SMTP_SERVICE` | 使用 QQ 邮箱时填 `QQ` |
| `SMTP_USER` | 发件邮箱完整地址 |
| `SMTP_PASS` | 邮箱提供的 SMTP 授权码，直接填写到 Vercel |
| `REGISTRATION_OPEN` | 首次部署先留空；管理员账号建立后再填 `true` |

也可使用其他 SMTP 服务商；如果不支持 `SMTP_SERVICE` 简写，填写 `SMTP_HOST`、`SMTP_PORT` 和 `SMTP_SECURE`。密钥和授权码不要放到站点设置。

服务端代码已固定设置 `LOGIN=force`、`COMMENT_AUDIT=true`，同时隐藏设备和 IP 归属地显示。显示隐藏不代表服务端不处理 IP：Waline 仍会处理必要的账号、评论和防灌水信息。

## 建立管理账号并开放评论

1. 部署成功后，访问评论服务地址的 `/ui/register`。
2. 使用 `OWNER_EMAIL` 填写的邮箱注册，并完成邮件确认。Waline 的首个注册用户会成为管理员；首次配置期间代码只允许这个邮箱注册。
3. 登录 `/ui`，确认能看到评论管理后台。
4. 在 Vercel 添加 `REGISTRATION_OPEN=true`，重新部署评论服务。
5. 如果使用自定义评论域名，先绑定域名，再把 `SERVER_URL` 设置为其完整 HTTPS 地址。可通过 `SECURE_DOMAINS` 同时限定博客域名与评论服务域名。
6. 在 Pages CMS → 站点设置 → **评论服务地址** 填写评论服务的 HTTPS 地址，保存。Cloudflare 部署后，文章底部自动启用评论和点赞。

先用普通读者账号提交一条评论：它应显示待审核，未登录窗口不应看到。管理员在 `/ui` 选择通过后，再次刷新普通窗口，才应公开显示。

## 点赞与分享

- 点赞使用 Waline 的文章 reaction0 计数，支持再次点击取消。当前浏览器会记住操作状态；这是轻量互动计数，不承诺每个真实用户只能投一票。
- 分享优先使用浏览器系统分享，不支持时复制文章链接。剪贴板不可用时会显示可手动复制的链接。
- 互动数据不进入 Pagefind 搜索结果，统计浏览量继续由现有 Cloudflare Web Analytics 提供。
- 邮件更新订阅不包含在本次功能中，注册评论账号不会自动订阅博客更新。

## 可选的防垃圾与维护

Waline 默认限制同一 IP 的提交频率；审核期间可以删除垃圾评论。需要验证码时，在评论服务设置 `TURNSTILE_SECRET`，在 Pages CMS 填写公开的 `评论验证码 Site Key`，双方一起启用。

定期从 Neon 导出评论库备份。审核、回复和删除在 Waline 后台进行；文章仍在 Pages CMS 编辑。评论服务暂时不可用时，文章、补丁下载和复制链接仍可使用。
