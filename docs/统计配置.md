# 博客浏览与补丁下载统计

## 1. 浏览统计

Cloudflare → Workers 和 Pages → 你的博客项目（部署域名为 `my-blog-pgn.pages.dev`）→ Metrics（指标）→ Web Analytics → Enable（启用）。

启用后需要一次新部署，Cloudflare 才会自动把统计脚本加入网页。之后通过 Metrics 中的 **View Web Analytics** 查看浏览数据，不需要在 Pages CMS 中填写代码。浏览器广告拦截或禁用 JavaScript 会造成漏计。

## 2. 创建下载数据库

Cloudflare → Storage & databases（存储和数据库）→ D1 SQL database → Create Database。

- 名称：`my-blog-downloads`
- 其他设置先保持默认。

进入这个数据库的 Console（控制台），粘贴以下语句并点击 Execute（执行）：

```sql
CREATE TABLE IF NOT EXISTS download_daily (
  day TEXT NOT NULL,
  file TEXT NOT NULL,
  requests INTEGER NOT NULL DEFAULT 0 CHECK (requests >= 0),
  PRIMARY KEY (day, file)
);
```

这与仓库 `migrations/0001_download_daily.sql` 一致。重复执行不会删除已有数据。

## 3. 绑定 Pages 项目

Cloudflare → Workers 和 Pages → 你的博客项目（部署域名为 `my-blog-pgn.pages.dev`）→ Settings（设置）→ Bindings（绑定）→ Add → D1 database。

- 环境：Production（生产）。
- Variable name（变量名称）：`DOWNLOAD_DB`，注意大写和下划线。
- D1 database：选择 `my-blog-downloads`。

保存后，进入 Deployments（部署），对**最新生产部署**选择 Retry deployment（重试部署；部分界面显示 Redeploy）。数据库绑定和 Web Analytics 均会在新部署中生效。预览环境不用绑定生产数据库。

不需要创建单独的 Worker，也不需要 API Token。

## 4. 查看下载量

进入 D1 → `my-blog-downloads` → Console，执行下面的查询。

### 每个补丁的累计下载请求数

```sql
SELECT file AS patch, SUM(requests) AS downloads
FROM download_daily
GROUP BY file
ORDER BY downloads DESC;
```

### 最近 30 天，每天每个补丁的下载请求数

```sql
SELECT day, file AS patch, requests AS downloads
FROM download_daily
WHERE day >= date('now', '+8 hours', '-29 days')
ORDER BY day DESC, requests DESC;
```

这些数据只在你登录的 Cloudflare 后台查看，网站没有公开统计读取接口。

## 统计口径

- 只统计正式域名 `blog.yychess.top` 的 `/downloads/` 下 zip、7z、rar、gz、xz 文件，以北京时间按天汇总。现有链接不用更换，以后新上传的文件也自动适用。
- 记录下载开始请求，不能证明文件完整下载成功，也不是独立下载人数。重复点击可能计多次。
- 跳过 HEAD 请求、断点续传 Range 请求、206 分段响应、明确标记的预加载、常见爬虫与失败请求。所有请求都使用 Range 的下载器可能漏计；简单过滤也不能识别所有机器人。
- 仅保存日期、公开文件名和次数，不保存 IP、邮箱或用户标识。预览部署和 `pages.dev` 地址不计数。
- 外部网盘的直接链接不经过这个入口，暂不统计。
- 数据库未绑定或暂时不可用时，仍正常返回补丁文件，只会漏记次数。只有下载路径使用 Pages Functions，文章和图片继续走静态托管。
- Web Analytics 和下载计数都从启用后开始，无法补回此前的历史数据。

官方说明：[Pages Web Analytics](https://developers.cloudflare.com/pages/how-to/web-analytics/)、[Pages D1 绑定](https://developers.cloudflare.com/pages/functions/bindings/#d1-databases)。
